# היפוך עברית (Hebrew Reverse)

תוסף ל-VS Code שהופך טקסט עברי שנכתב בסדר אותיות הפוך. למשל `"םולש"` הופך ל-`"שלום"`, בדיוק באותו מקום בשורה. אותיות בשפות אחרות ומספרים לא משתנים.

הפעולה סימטרית: הפעלה שנייה מחזירה את הטקסט למצב המקורי, כך שאפשר להשתמש בה לשני הכיוונים.

## שימוש

פותחים קובץ ומפעילים את הפקודה **היפוך טקסט עברי** (`Reverse Hebrew Text`) באחת מהדרכים:

- הכפתור ⇄ בסרגל הכותרת של העורך (מימין למעלה)
- קליק ימני בתוך העורך
- לוח הפקודות (`Ctrl+Shift+P`)

אם יש טקסט מסומן, רק הוא מטופל. בלי סימון, כל הקובץ מטופל. כל ההיפוכים נכנסים כצעד עריכה אחד, כך ש-`Ctrl+Z` אחד מבטל את הכול.

## מה בדיוק מתהפך

בברירת המחדל (מצב `phrase`) ביטוי עברי שלם מתהפך בבת אחת, כך שגם סדר המילים מתוקן:

| לפני | אחרי |
| --- | --- |
| `print("םולש")` | `print("שלום")` |
| `"!םלוע םולש"` | `"שלום עולם!"` |
| `"םירפס 15 יל שי"` | `"יש לי 15 ספרים"` |
| `"דואמ Visual Studio Code בהוא ינא"` | `"אני אוהב Visual Studio Code מאוד"` |
| `"(םלוע) םולש"` | `"שלום (עולם)"` |
| `["םולש", "הדות"]` | `["שלום", "תודה"]` |
| `return םולש` | `return שלום` |

הכללים:

- ביטוי מתחיל ומסתיים במילה עברית, ונמשך דרך רווחים וסימני פיסוק רגילים (`, . ; : ! ? - ( )`).
- מספר או מילה לועזית **בין** מילים עבריות עוברים מקום יחד עם הביטוי, אבל התווים שלהם נשארים כמו שהם.
- מספר או מילה לועזית **בקצה** הביטוי לא זזים. לכן `"5 תודוקנ"` הופך ל-`"5 נקודות"`.
- מירכאות, סוגריים מרובעים ומסולסלים, אופרטורים, טאב וסוף שורה תמיד מפרידים בין ביטויים. גם פסיק או נקודה בלי רווח מפרידים, כך ששדות CSV ושמות קבצים לא מתערבבים (`םולש,הדות` הופך ל-`שלום,תודה`).
- סוגריים עגולים בתוך ביטוי מתהפכים לכיוון הנכון.
- ניקוד נשאר צמוד לאות שלו. גרש ומירכאות בתוך מילה (`צה"ל`, `ג'ירף`) נשארים חלק מהמילה.

התוסף לא מנחש אם הטקסט הפוך או תקין: כל טקסט עברי בטווח מתהפך. אם בקובץ יש גם עברית תקינה, מסמנים רק את החלק שצריך להפוך.

## הגדרות

| הגדרה | ברירת מחדל | תיאור |
| --- | --- | --- |
| `hebrewReverse.mode` | `phrase` | `phrase`: היפוך ביטוי שלם. `word`: היפוך כל מילה עברית במקומה, בלי להזיז שום דבר אחר בשורה. |
| `hebrewReverse.showEditorTitleButton` | `true` | הצגת הכפתור בסרגל הכותרת של העורך. |

## פיתוח

```bash
npm install
npm test          # קומפילציה והרצת הבדיקות
npm run package   # יצירת קובץ ‎.vsix להתקנה
```

להרצה מתוך VS Code: פותחים את התיקייה `hebrew-reverse` ולוחצים `F5`. נפתח חלון חדש שבו התוסף פעיל.

להתקנה מקובץ: `Extensions` ← `...` ← `Install from VSIX...`, או `code --install-extension hebrew-reverse-0.1.0.vsix`.

מבנה הקוד:

- `src/hebrew.ts`: לוגיקת האיתור וההיפוך. מחרוזות בלבד, בלי תלות ב-VS Code.
- `src/extension.ts`: הפקודה, הטיפול בסימון והחלת העריכות בעורך.
- `src/test/hebrew.test.ts`: בדיקות.
- `package.nls*.json`, `l10n/`: תרגום הממשק לאנגלית ולעברית.

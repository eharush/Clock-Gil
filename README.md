# שעון גיל

משחק ווב בעברית ללימוד קריאת שעון מחוגים, בשמונה שלבים מדורגים. כל שלב מתחיל בהסבר קצר עם שעון שאפשר לגעת בו, וממשיך בתרגול.

| שלב | נושא |
| --- | --- |
| 1 | הכירו את השעון: 12 המספרים, ארבעת עמודי התווך (12, 3, 6, 9) וכיוון השעון |
| 2 | מחוג קצר (שעות, כתום) ומחוג ארוך (דקות, כחול) |
| 3 | שעה עגולה, וסיבוב שלם של המחוג הארוך = שעה |
| 4 | קפיצות של 5 דקות: השנתות, וכל מספר שווה ×5 דקות |
| 5 | חצי שעה |
| 6 | רבע שעה: "ורבע" ו"רבע ל..." |
| 7 | קריאת כל שעה בקפיצות של 5 דקות |
| 8 | אתגר: כיוון השעון לפי שעה שכתובה במילים |

יש גם **שעון חופשי** שבו אפשר לגרור את המחוגים לכל מקום ולראות את השעה בספרות ובמילים.

סוגי התרגול: לחיצה על מקום של מספר, זיהוי מחוג, בחירת תשובה, וגרירת מחוגים לשעה מבוקשת. אחרי טעות מופיע רמז, ולפעמים גם עזר על השעון (למשל תוויות הדקות מסביב). ההתקדמות והכוכבים נשמרים בדפדפן.

## הרצה

אין צורך בהתקנה או בבנייה. פותחים את `index.html` בדפדפן, או מגישים את התיקייה מכל שרת סטטי (למשל GitHub Pages).

## מבנה

- `js/clock.js`: רכיב שעון SVG עם אנימציה, גרירת מחוגים (עכבר, מגע ומקשי חצים) ולחיצה על מספרים
- `js/levels.js`: תוכן השלבים, ההסברים ומחוללי השאלות, כולל ניסוח השעה בעברית
- `js/app.js`: המסכים, הניקוד, הצלילים והשמירה
- `css/style.css`: העיצוב
